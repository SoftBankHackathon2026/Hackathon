# Harbor 준비 모듈 검증 기록

기준일: 2026년 11월 7일. **코드·로컬 검증을 완료했으며, 운영 서버에 설치하거나 실제 이관을 수행한 기록은 아닙니다.**

## 실행한 검사

Python 3.12.14의 독립 가상환경에서 전체 이관 검사는 **289개 통과·24개 생략**입니다. 이 중 새 Harbor 검사는 **82개 통과**입니다. 생략한 기존 검사는 실제 PostgreSQL 접속 정보가 필요한 8개와 OPA 실행 도구가 필요한 16개입니다.

```sh
python -m pytest -o addopts='' --tb=short -q
ruff check --isolated --select E9,F,I migration/harbor_infra tests/harbor_infra
ruff format --check migration/harbor_infra tests/harbor_infra
python -m build --no-isolation
```

위의 제품·클러스터 응답 모형 검사는 실제 Harbor·Keycloak·Kubernetes의 동작 검증을 대체하지 않습니다. 공식 Harbor 2.14.6 온라인 설치기와 Docker 공식 공개키의 실제 다운로드 검증값, 공식 Ubuntu 패키지 목록을 확인해 배포 목록에 고정했습니다. Harbor 컨테이너 자체를 기동해 검증한 기록은 없습니다.

## 실제 환경에서 추가 확인할 항목

1. Ubuntu 24.04·amd64 시험 노드를 선택하고 노드 고유 식별자·machine-id·이름 해석·호스트 키·관리 권한과 자료 참조를 준비합니다. 기존 Kubernetes 실행 기반과 Docker 의존성·방화벽·포트·별도 데이터 마운트를 확인합니다.
2. `preflight`의 변경 목록을 검토하고 요약값으로 `install`을 호출합니다. 공식 `prepare`, 전용 Compose·서비스·내부 DB·Redis, 외부 HTTPS 접속과 기존 클러스터 정상 상태를 확인합니다.
3. 같은 입력의 재실행, 단계 중단·재개, 관리 파일 변경 거부를 확인합니다. 별도 운영 절차로 호스트를 재부팅해 마운트 누락 시 기동 거부와 정상 마운트에서의 자동 기동을 확인합니다.
4. 기존 또는 자체 생성 인증서의 이름·신뢰·만료를 확인하고, 실제 Keycloak 전용 client와 사용자·그룹을 준비합니다. Harbor 로그인·역할 대응을 브라우저에서 확인합니다.
5. `configure`와 인계 준비·수령 확인을 수행하고, 원문이 일반 결과·플랫폼 로그에 남지 않는지 확인합니다. 인계 영역의 접근 통제·암호화·기한 작업은 플랫폼 연결과 함께 확인합니다.
6. `trust`를 선택 노드별로 수행합니다. k3s·일반 containerd·Docker 각각의 실제 버전에서 반영과 재시작 필요 여부를 확인합니다. 승인하지 않은 노드와 기존 레지스트리·미러·인증이 유지되는지 확인합니다.
7. 전용 시험 프로젝트·네임스페이스와 필요한 권한을 명시하고 이미지 시험을 켭니다. 실제 Harbor에서 쓰기·읽기·거부·내용 일치와 실제 노드 이미지 다운로드, 시험 자원 정리를 확인합니다. 기존 조직의 정책을 시험 편의로 해제하지 않습니다.
8. 별도 이관 도구에서 ECR 읽기와 Harbor 쓰기 계정을 연결해 실제 이미지 이관을 검증합니다. 이후 앱의 읽기 자격증명·이미지 주소 연결을 별도 플랫폼 작업으로 검증합니다.

현재 자동 검증은 브라우저 로그인, 실제 서버의 신규 설치·마운트 후 기동, 실제 노드 신뢰 반영, 플랫폼의 작업 전달·다운로드·외부 비밀 저장, 운영 데이터 백업·복구, 실제 ECR 업무 이미지 복사를 완료로 표시하지 않습니다. 임시 시험 객체 정리에 실패하면 `KUBERNETES_PROBE_CLEANUP_FAILED`로 반환합니다. 전용 시험 공간에서 `app.kubernetes.io/managed-by=oneport-harbor-probe` 표식과 실행 기록을 확인해 남은 객체를 정리해야 합니다.

용어: OPA는 외부 정책 판단 도구, OIDC는 사용자 로그인 연동 표준, TLS·HTTPS는 서버 신원 확인과 통신 암호화입니다. Pod는 Kubernetes의 컨테이너 실행 단위이며 Secret은 자격증명을 전달하는 객체입니다.
