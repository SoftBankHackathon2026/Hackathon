새 기능 최종 실행 명령은 저장소 루트 기준 다음과 같습니다. 시험용 비밀번호와 주소는 운영 값이 아닌 일회용 로컬 값입니다.

```sh
OPENBAO_TEST_BINARY=/path/to/test/bao \
MIGRATION_TEST_DSN=postgresql://test-admin:test-only@127.0.0.1:TEST_PORT/postgres \
IDENTITY_REFERENCE_ROOT=/path/to/unchanged/identity-pr51 \
python -m pytest migration/tests/secrets_migration --tb=short -ra
```

`MIGRATION_TEST_DSN`은 일회용 PostgreSQL 접속 문자열입니다. 실제 PostgreSQL 시험은 숫자 루프백 주소와 비밀번호를 요구하고 시험용 역할·데이터베이스를 정리합니다. `IDENTITY_REFERENCE_ROOT`는 변경하지 않은 계정 PR의 저장소 경로입니다. 자동 검사에서도 해당 커밋을 별도 위치에 받아 같은 검사를 실행합니다.

기존 기능 회귀는 별도 인프라 실행 환경에서 `migration` 디렉터리를 작업 위치로 사용합니다.

```sh
python -m pytest -m 'not openbao_live and not secrets_live and not wazuh_live' --ignore=tests/secrets_migration --tb=short -ra
python -m pytest tests/test_keycloak_ansible.py tests/test_policy_client.py -k 'real_ansible or examples_match_expected or gate_end_to_end_with_rego or rollback' --tb=short -ra
```
